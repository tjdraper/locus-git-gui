# Locus Git Gui

A Git client for the Mac that feels at home there, can be driven entirely from the keyboard, and does Git rather than things next to Git. It runs your own `git`, so hooks, credential helpers, signing and the rest of your setup behave exactly as they do in Terminal.

It's in early development. [`Plans/HighLevelPlan.md`](Plans/HighLevelPlan.md) has what's planned and why.
