# Contributing

Locus Git Gui's source is public so people can read it, but it is not open source. It's published under the [PolyForm Strict License 1.0.0](LICENSE), which doesn't allow changing the code or distributing it. Contributions are still welcome, under the two terms below.

## Permission to prepare a contribution

The PolyForm Strict License doesn't allow changes to the software, and a pull request is a change. So, in addition to that license, TJ Draper grants you permission to:

- copy and change the software, only to prepare a contribution to this repository (`github.com/tjdraper/locus-git-gui`)
- build and run your changed copy, only to test that contribution
- publish your changes in a fork on GitHub, only so you can open a pull request from it

This permission doesn't let you use, distribute or build on your changed copy for any other purpose. It ends for a given change once its pull request is merged or closed, apart from keeping your fork on GitHub.

## Contributor License Agreement

Before a pull request can be merged, its author signs the agreement below. You sign once, and it covers every contribution you make afterwards.

To sign, open your pull request. A bot comments on it asking you to sign. Reply with this comment, exactly:

```
I have read the CLA Document and I hereby sign the CLA
```

The bot records your GitHub username and the date in this repository, and the pull request's CLA check passes. If the check doesn't update, comment `recheck`.
